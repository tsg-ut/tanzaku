tanzaku
=======

INORI

# これなに

* 焼き肉食べたい
* 寿司食べたい

などのissue を立てて, みんなで予定を合わせて願いを叶えよう！

## 使い方

1. このリポジトリにissueを立てて、あなたの願いを書いてください
2. issueは自動的に短冊ギャラリーに表示されます
3. 願いが叶ったら、issueをcloseしてください

## issueをcloseする条件

issueは以下のような場合にcloseすることができます：

* 願いが叶った・実現した時
* 願いを取り下げたい時
* 別の願いに変更したい時

具体的な例については、[ISSUE_CLOSURE_CONDITIONS.md](ISSUE_CLOSURE_CONDITIONS.md) を参照してください。
